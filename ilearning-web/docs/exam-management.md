# 考试管理设计与实现

本文档记录考试活动管理模块（`exam`）的设计决策与实现边界。数据库结构沿用
[`online-examination-database-design.md`](./db/online-examination-database-design.md)，本模块不修改 DDL。

## 1. 职责边界

- **试卷（paper）**：固定“考什么”——题目集合、题序、每题分值和试卷总分。
- **考试（exam）**：定义“怎么考”——引用试卷、开放时间、单次时长、参加次数和及格线。
- **考试记录（exam_attempt / exam_answer）**：某位考生的一次实际作答过程，不属于本模块。

本模块只实现管理端的考试活动配置与生命周期，不包含考生作答、判分、成绩查询。
考试始终引用一份**已发布**的试卷；试卷发布后内容冻结，因此考试内容在活动生命周期内保持稳定。

## 2. 生命周期

```text
草稿(0) --发布--> 已发布(1) --关闭--> 已关闭(2)
```

| 状态 | 编辑 | 删除 | 可被考生参加 |
|---|---|---|---|
| 草稿 0 | 允许 | 允许（无考生记录时） | 否 |
| 已发布 1 | 禁止 | 禁止 | 是（且需在开放时间内） |
| 已关闭 2 | 禁止 | 禁止 | 否 |

规则：

1. 新建考试一律为草稿。
2. 草稿只能引用已发布试卷；已引用的试卷之后被归档时，仍允许继续保存草稿，但切换试卷必须选择已发布试卷。
3. 发布时再次校验试卷仍为已发布状态、及格线不超过试卷总分、开放时间先后关系合法。
4. 状态流转使用 `UPDATE ... WHERE id=? AND status=<预期状态>`，并发下只有一个请求能成功。
5. 删除仅限草稿，并防御性检查 `exam_attempt` 是否已有记录。

## 3. 开放时间与参加规则

| 字段 | 语义 |
|---|---|
| `start_time` | 开放开始时间；`NULL` 表示不限制开始时间 |
| `end_time` | 开放结束时间；`NULL` 表示不限制结束时间 |
| `duration_minutes` | 单次考试时长；`0` 表示不限时 |
| `max_attempts` | 每位考生的参加次数；`0` 表示不限次数 |
| `passing_score` | 本场考试的及格线，不得超过所引用试卷的总分 |

活动状态与开放时间相互独立：`status = 1` 且尚未到 `start_time` 时仍不可参加；
即使未到 `end_time`，`status = 2` 也不允许新的考试开始。管理端列表在此之上派生出
“未开始 / 进行中 / 已结束”的展示状态，仅用于展示，不改变数据库状态。

考试关闭目前由管理员显式操作，不按 `end_time` 自动改写状态。

## 4. 接口契约

所有接口仅 `ADMIN` 可访问（`SecurityConfig`），统一返回 `Result<T>`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/exams?page&pageSize&keyword&status&paperId` | 分页列表，关联返回试卷标题、总分和状态 |
| GET | `/exams/{id}` | 考试详情（含试卷信息） |
| POST | `/exams` | 新建考试草稿，返回考试 id |
| PUT | `/exams/{id}` | 保存考试草稿（仅草稿） |
| PUT | `/exams/{id}/publish` | 草稿 → 已发布 |
| PUT | `/exams/{id}/close` | 已发布 → 已关闭 |
| DELETE | `/exams/{id}` | 删除考试草稿 |

请求体：

```json
{
  "paperId": 1,
  "title": "羽毛球规则月度考试",
  "description": "面向全体员工的月度考核",
  "durationMinutes": 60,
  "maxAttempts": 1,
  "passingScore": 60,
  "startTime": "2026-11-01T09:00:00",
  "endTime": "2026-11-30T18:00:00"
}
```

分页响应中的单条记录：

```json
{
  "id": 1,
  "paperId": 1,
  "paperTitle": "羽毛球规则月度试卷",
  "paperTotalScore": 100,
  "paperStatus": 1,
  "title": "羽毛球规则月度考试",
  "description": "面向全体员工的月度考核",
  "durationMinutes": 60,
  "maxAttempts": 1,
  "passingScore": 60,
  "startTime": "2026-11-01T09:00:00",
  "endTime": "2026-11-30T18:00:00",
  "status": 1,
  "createdBy": 1,
  "createdAt": "2026-10-22T20:00:00",
  "updatedAt": "2026-10-22T20:00:00"
}
```

## 5. 一致性与校验

- 分页：`page >= 1`，`pageSize <= 100`；关键词匹配考试名称、说明或试卷名称。
- 标题最长 128 位，说明最长 1000 位；时长与次数范围为 `0 ~ 65535`。
- 及格线：`0 ~ 999999.99`，最多 2 位小数，且不得超过试卷总分。
- 开放时间：两者同时存在时，结束时间必须晚于开始时间。
- 编辑、发布、关闭、删除均为单事务；状态更新带预期状态条件。
- 删除草稿前检查 `exam_attempt`，避免历史记录失去所属活动。

## 6. 前端结构

- `/exams`：考试列表（关键词/状态筛选、分页、桌面表格 + 移动端卡片）。
- `ExamEditorDrawer`：考试名称、可搜索的已发布试卷选择、开放时间、时长、次数、及格线；
  试卷总分实时提示，及格线在前端先做一次上限校验。
- `ExamDetailDrawer`：考试规则与试卷信息，试卷不可用时给出警告。
- 列表操作：详情、编辑草稿、发布、关闭、删除；发布前提示规则将冻结。

## 7. 暂未实现

- 考生参加考试、作答、判分与成绩查询（`exam_attempt` / `exam_answer`）。
- 到达 `end_time` 后自动关闭活动。
- 考试复制、模板与批量排期。
- 考试与试卷归档的联动提示（当前发布时会拒绝不可用试卷，已发布考试继续使用冻结的试卷快照）。
